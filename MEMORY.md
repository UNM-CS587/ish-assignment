# File containing AI-generated notes from previous sessions to allow 
# agents to preserve key information between runs

This file starts empty. At the end of each working session, ask your agent to
fill in the sections below, and read them back at the start of the next one.

## Current State

What feature or bug you were working on, and where it stands: done, blocked,
or half-implemented.

## Design Decisions

Choices you made and the reasoning behind them, especially the ones that are
not obvious from reading the code.

## Open Questions and Next Steps

What you or your agent still need to resolve, and where to pick up.
